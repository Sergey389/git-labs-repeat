## Git aliases

| Alias | Command |
|---|---|
| git st | git status |
| git ci | git commit |
| git co | git checkout |
| git br | git branch |
| git df | git diff |
| git lg | git log --oneline --decorate --all --graph |
| git recent | git log --oneline -n 5 |

Aliases simplify frequently used Git commands.
